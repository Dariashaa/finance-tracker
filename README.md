# Личный финучёт

Веб-приложение для учёта личных доходов и расходов: операции, категории, бюджеты, отчёты и экспорт данных.

## Назначение

Приложение помогает видеть, сколько человек зарабатывает и тратит, на что уходят деньги и укладывается ли он в запланированные лимиты по категориям.

## Основные пользовательские сценарии

1. **Добавить операцию**: указать сумму, дату, категорию и комментарий (расход или доход).
2. **Просмотреть операции за период**: текущий месяц, выбор другого месяца, фильтр по категории.
3. **Отредактировать или удалить операцию**, если допущена ошибка.
4. **Управлять категориями**: создать, переименовать, изменить цвет, удалить.
5. **Задать бюджет**: установить лимит расходов по категории и видеть, сколько уже потрачено.
6. **Посмотреть отчёты**: расходы по категориям, динамика по месяцам, соотношение доходов и расходов.
7. **Экспортировать данные** за выбранный период в CSV.

## Экраны

### 1. Главная (операции)

Экран разделён на две колонки: **слева расходы, справа доходы**.

- Сверху: выбор месяца и итоги (доходы, расходы, баланс).
- В каждой колонке: заголовок с суммой, кнопка «+ Добавить» и список операций.
- Операция отображается компактной строкой: дата, описание, цветной бейдж категории, сумма. Комментарий и кнопки «изменить» / «удалить» появляются при наведении или клике на строку.
- Показываются последние 10-15 операций месяца и ссылка «Показать все».
- Добавление и редактирование операции происходит в модальном окне.
- Рядом с расходами выводится краткий блок о бюджетах (например, «Еда: 82% лимита»), чтобы предупреждения были видны сразу.
- На узких экранах колонки превращаются в вкладки «Расходы | Доходы».

### 2. Категории и бюджеты

Список категорий в двух группах: расходы и доходы.

- Строка категории: цветная точка, название, «потрачено / лимит», полоска прогресса, кнопки «изменить» и «удалить».
- Цвет полоски: зелёная до 70%, жёлтая 70-100%, красная при превышении лимита.
- Лимит необязателен: без лимита полоска не показывается, выводится только сумма расходов.
- У категорий доходов бюджета нет.
- Создание и редактирование категории выполняется в модальном окне: название, тип (расход / доход), цвет, лимит в месяц (только для расходов).

### 3. Отчёты

- Выбор периода.
- Круговая диаграмма расходов по категориям.
- Столбчатая диаграмма доходов и расходов по месяцам.
- Кнопка **«Экспорт»** (CSV за выбранный период).

Отдельный экран экспорта не нужен: период уже выбран на странице отчётов.

### 4. Форма добавления операции (модальное окно)

Поля: тип (расход / доход), сумма, дата, категория, комментарий.

## Принятые решения

- Лимит категории один и действует на каждый месяц; «потрачено» считается по операциям выбранного месяца.
- Категорию, в которой есть операции, удалить нельзя: сначала нужно удалить или перенести операции.
- Цвет категории задаётся один раз и используется в списках, бейджах и графиках.
